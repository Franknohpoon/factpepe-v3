## 1. 신규 기능

### 1) 이닝별 라이브 투표
- 경기 중 운영자가 이닝별 폴 발행 가능 (3종 템플릿: SSG 점수 / 다음 타석 / 이닝 결과)
- 사용자: 1표/폴, 마감 후 결과 막대 + 정답 확정 시 "🎯 적중" 표시
- 위치: 토스 앱 홈 탭 (투표 카드 아래)
- 운영: `/q → ⚡ 라이브` 탭

### 2) 운영자 부재 대안 — 자동 폴 + 자동 정답
- 매일 오후 4시 자동으로 "오늘 SSG 총득점" 폴 1개 생성 (옵션 0~2 / 3~4 / 5~6 / 7+점)
- 다음 날 새벽, 어제 결과로 자동 정답 확정 → 사용자에게 적중 피드백
- 운영자가 없어도 매 경기 1건의 라이브 콘텐츠 보장

### 3) AI 자동 하이라이트 카드
- 경기 종료 직후 페페가 어제의 한 장면을 자동 요약
- 룰 기반 헤드라인 + 한 줄 요약 + 페페 한 마디 + 표정
- 결과별 좌측 컬러바(승 빨강 / 패 그레이 / 무 블루)
- 위치: 홈 탭, 분석 카드 위

### 4) 푸시 알림 동의 카드
- 토스 스마트 발송과 연동되는 동의 UI
- 시나리오 2종 준비: 경기 시작·결과 / 적중·직관
- 동의문 templateCode 환경변수 미설정 시 카드 자동 숨김 → 출시 안전
- 위치: 토스 앱 MY 탭

### 5) 운영자 콘솔 `/q` 4탭 구조
- 📡 라인업 (트윗 붙여넣기 + 네이버 자동 불러오기)
- 📊 예측 (오늘 팩트 승률 직접 설정)
- ⚡ 라이브 (이닝별 폴 발행/정답/마감)
- 🍽️ 먹거리 (랜더스필드 가게 CRUD)

## 2. 안정성·신뢰성 개선

### 1) 휴식일 분석 폴백
- 월요일 등 경기 없는 날, 다음 경기 분석을 미리 표시
- `prediction-auto`가 4일 이내 다가오는 경기 자동 탐색

### 2) 오늘 상대팀 표시 정확도 향상
- 헤더의 "vs 상대팀"이 어제 경기로 표시되던 버그 수정
- 우선순위: `games/{오늘}`(스케줄 진실) → 오늘자 라인업 → 예측

### 3) 직관 기록 / 일정 변동 대응
- 매일 KST 23:30 · 01:00 어제~3일 후 SSG 경기 자동 수집
- 일정 변경/우천 취소도 자동 반영
- 직관 분석에 "구장별 · 상대별" 토글 추가, 행 탭 시 일지 필터

### 4) /q 운영자 인증 강화
- PIN을 서버 환경변수(`ADMIN_PIN`)에서만 검증, 클라이언트 번들에 노출되지 않음
- HMAC 서명 단기 토큰(8시간) 발급
- 라인업/먹거리/예측 모든 쓰기를 서버 API(`/api/admin-write`)로 우회

### 5) 토스 SDK 안전 래퍼
- `closeView` / `graniteEvent` / `requestNotificationAgreement` 호출을 토스 외 환경(브라우저)에서 no-op 처리
- 검수 통과 후 외부 노출 환경에서도 크래시 없이 동작

### 6) 라인업 입력 자동완성 보강
- 최정·김재환·에레디아·고명준·신범수·홍대인 포지션 시드 정정
- 중복된 "기예르모 에레디아"를 "에레디아"로 통일

## 3. 디자인 전면 개편

### 1) 듀얼 컬러 시스템
- SSG 레드 = 정체성(직관·응원·결과)
- 토스 블루 = 데이터(분석·적중률·정보)
- 카드별 좌측 컬러 바 3px로 카테고리 즉시 인지

### 2) 콘덴스드 히어로 숫자 + 크로스해치 텍스처
- 직관 승률 / 팩트 승률 / 어제 스코어 등 핵심 수치 통일 톤
- 시스템 폰트 기반(추가 폰트 다운로드 없음)

### 3) 티켓형 직관 승률 공유 카드
- 빨강 배경 + 큰 승률 숫자 + 페페 + 점선 퍼포레이션 + 세로 브랜드
- "📤 직관 승률 공유" 버튼으로 카드 다운로드/공유

### 4) 직관 분석 카드 리디자인
- 히어로 + 채움 행(승률만큼 배경 채워짐) + KBO 9팀 전체 노출(기록 없으면 회색)
- 상대구단별 / 구장별 토글
- 항목 탭 시 아래 일지 필터링

### 5) 직관 기록 입력 모달
- 응원팀(페페) VS 상대팀(이니셜 원형) + 큰 콘덴스드 스코어
- 결과 배지 + 홈/원정·구장 한 줄 정리

### 6) 이모지 정리 + 타이포 위계
- 섹션 이모지(🏟️🍽️📊 등) 제거 → 색·크기·굵기로 위계
- 라운드 카드 16px / 내부 10px 통일

## 4. 검수 가이드 충족

이전 빌드부터 유지되는 항목, 이번 빌드에도 그대로 적용됨:

- ✅ 표준 비게임 내비게이션 바 (`webViewProps.type: 'partner'`, 뒤로가기/홈 버튼)

- ✅ 네이티브 뒤로가기 + AOS 시스템 백버튼 → 모달→탭→종료 우선순위
- ✅ 더보기(⋯) 버튼 자동 제공 (표준 네비바)
- ✅ 라이트 모드 강제 (`color-scheme: light`)
- ✅ 제스처 줌 비활성 (`user-scalable=no`)
- ✅ CSR 전용, eval 없음, https 통신, 진입 즉시 모달 없음
