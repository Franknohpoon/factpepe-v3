# 팩트페페:인천 야구 — 디자인 시스템 (리뷰용)

토스 미니앱 "팩트페페:인천 야구"의 디자인 컨텍스트 문서입니다.
클로드 디자인 리뷰 시 이 문서 + `screens/` 스크린샷 + `tossTheme.js`를 함께 봐주세요.

---

## 0. 한눈에

- **정체성**: SSG 랜더스(KBO) 팬을 위한 데이터·기록 미니앱
- **마스코트**: 초록 개구리 캐릭터 **페페**(Pepe) — 7가지 표정
- **플랫폼**: 토스 미니앱 (WebView, 모바일 세로 전용, 라이트 모드 강제)
- **레이아웃**: 하단 4탭 (홈 / 직관 / 먹거리 / MY) + 카드 스택
- **디자인 방향**: "토스의 깔끔함 + SSG 정체성" — 최근 레퍼런스 기반으로
  듀얼 컬러 + 콘덴스드 히어로 숫자 + 크로스해치 텍스처로 개편

## 1. 컬러 시스템 (듀얼 컬러)

색을 **의미로 분리**한 것이 핵심. 소스: `src/tossTheme.js`

| 역할 | 컬러 | 값 | 사용처 |
|---|---|---|---|
| **정체성·감정** | SSG 레드 | `#CE1141` | 직관/응원/투표/결과, 카드 좌측 3px 바 |
| **데이터·분석** | 토스 블루 | `#3182F6` | 승률/적중률/분석, 카드 좌측 3px 바 |
| 배경 | 라이트 그레이 | `#F9FAFB` | 앱 배경 |
| 카드 | 화이트 | `#FFFFFF` + 보더 `#F1F3F5` | 모든 카드 |
| 텍스트 | — | `#191F28` / `#4E5968` / `#8B95A1` | 위계 3단 (토스 톤) |
| 페페 그린 | — | `#4FAF35` | 캐릭터 전용 |

- **카드 좌측 3px 컬러바**로 카테고리(데이터=블루 / 정체성=레드)를 즉시 인지
- 그림자는 옅게 (`0 1px 3px rgba(17,24,39,0.05)`) — 토스 스타일

## 2. 타이포그래피

- 시스템 폰트 (`-apple-system, SF Pro`) — 별도 웹폰트 없음
- **히어로 숫자** (`HERO_NUM`): 승률·적중률·스코어 등 핵심 수치
  - `fontWeight: 900`, `letterSpacing: -0.04em`, `tabular-nums`, 콘덴스드 느낌
  - 크기: 홈 분석 56px / 직관 승률 46px / MY 적중률 34px / 스코어 40px
- 위계: kicker(10px, 색·대문자) → 제목(15px, extrabold) → 본문(13px) → 메타(11px, muted)
- 이모지는 **거의 제거** — 색·굵기·크기로 위계 (음식 카테고리 이모지만 기능적으로 유지)

## 3. 공통 컴포넌트 프리미티브

`src/TossApp.jsx` 상단에 정의:

| 프리미티브 | 역할 |
|---|---|
| `cardStyle` | 카드 래퍼 (라운드 16px, 옅은 보더/그림자) |
| `ColorBar` | 좌측 3px 카테고리 바 (레드/블루) |
| `SectionHead` | kicker + 제목 + meta + action (이모지 없는 헤더) |
| `HERO_NUM` | 콘덴스드 athletic 숫자 스타일 |
| `crossHatch()` | 대각선 크로스해치 텍스처 (히어로 배경) |
| `FilledRow` | 승률만큼 배경이 채워지는 행 (직관 분석) |
| `ResultBadge` / `ResultDot` | 승/패/무 배지·점 (🔴⚪ 이모지 대체) |
| `TabBar` | 하단 플로팅 탭바 (인라인 SVG 아이콘) |

라운드: 카드 16px / 내부 요소 10px 로 통일.

## 4. 마스코트 — 페페 (Pepe)

- 초록 개구리 캐릭터, 승률·상황에 따라 표정 변화 (7종)
  - `excited`(신남) / `happy`(기쁨) / `analyzing`(분석/차분) / `sad`(아쉬움)
  - `cheering`(응원) / `cool`(쿨) / `sleepy`(대기)
- 규칙: 승률 ≥60 excited, ≥45 happy/analyzing, <45 sad
- 에셋: `public/pepe/pepe-*.png`
- **디자인 결정 사항**: 레퍼런스는 빨간 야구공 마스코트였으나, 페페 IP 유지를
  선택하고 레이아웃/타이포만 차용함. (리뷰 시 이 방향 유지 여부도 봐주세요)

## 6. 리뷰에서 봐주면 좋은 것

1. **듀얼 컬러(레드/블루)의 의미 분리**가 사용자에게 직관적으로 읽히는지
2. **콘덴스드 히어로 숫자 + 크로스해치**가 과하지 않고 일관적인지
3. **페페 유지 vs 야구공 마스코트** 방향성 (레퍼런스 대비)
4. 카드가 많은 스택 구조에서 **위계·여백·스캔 용이성**
5. 라이트 모드 단일 톤에서 **대비/접근성**
6. 공유 카드(티켓형/라인업)의 **SNS 임팩트**
