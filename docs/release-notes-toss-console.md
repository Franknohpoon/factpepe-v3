# 토스 콘솔 검토 메모 — 복붙용

> 콘솔의 "출시 노트" 또는 "검토 메모" 입력란에 그대로 붙여넣기.

---

## 📋 짧은 버전 (콘솔 입력란용, ~500자)

```
이전 통과 빌드 이후의 누적 업데이트입니다.

[신규 기능]
1) 이닝별 라이브 투표 — 운영자가 이닝별로 짧은 폴 발행, 사용자는 1표 후 결과·적중 확인
2) 운영자 부재 대안 — 매일 오후 4시 "오늘 SSG 총득점" 자동 폴 생성 + 다음 날 자동 정답 확정
3) AI 자동 하이라이트 카드 — 경기 종료 후 어제의 한 장면을 페페가 자동 요약
4) 푸시 알림 동의 카드 — 토스 스마트 발송 연동 준비 (동의문 등록 전엔 카드 자동 숨김)

[안정성]
- 휴식일(월요일)엔 다음 경기 분석으로 자동 폴백
- 헤더 상대팀이 어제 경기로 표시되던 버그 수정
- /q 운영자 콘솔: PIN을 서버 환경변수에서 검증하고 모든 쓰기에 HMAC 토큰 요구

[디자인]
- SSG 레드(정체성) + 토스 블루(데이터) 듀얼 컬러
- 콘덴스드 히어로 숫자 + 크로스해치 텍스처 통일
- 티켓형 직관 승률 공유 카드
- 직관 분석 카드: 구장별/상대별 토글, KBO 9팀 전체 노출

[검수 가이드 유지]
- 표준 비게임 네비바, 종료 확인 모달, 시스템 백버튼 종료 처리, 라이트 모드 강제, 제스처 줌 비활성 — 모두 그대로

확인 부탁드립니다. 감사합니다.
```
