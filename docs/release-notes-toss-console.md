# 토스 콘솔 검토 메모 — 복붙용

> 콘솔 "출시 노트/검토 메모" 입력란에 붙여넣기. (최신 빌드 `019f20c2…`)

---

## 📋 짧은 버전 (~500자)

```
이전 통과 빌드 이후 누적 업데이트입니다.

[라인업 입력 개선]
- X(트위터) 현장 기자 라인업 텍스트를 자동 인식 (포지션 코드 속기 형식)
  붙여넣기만으로 선발·타순·포지션 자동 채움. 네이버보다 빠른 반영.

[이미지 카드]
- 선발 라인업을 이미지 카드로 저장·공유 (캔버스 기반, 레드 헤더+9타순)

[라이브 투표]
- 경기 중 이닝별 투표 안정화(폴 생성 오류 수정)
- 운영자 부재 시에도 매 경기 자동 폴 1개 생성 + 종료 후 자동 정답

[운영]
- 운영자 콘솔 정리(먹거리 탭 제거), 사용자 화면은 그대로

[검수 가이드 유지]
- 표준 비게임 네비바, 종료 확인 모달, 시스템 백버튼 종료, 라이트 모드,
  제스처 줌 비활성 — 모두 그대로 유지

확인 부탁드립니다. 감사합니다.
```

```
정리: 운영자 콘솔 먹거리 탭 제거(사용자 화면 유지)

확인 부탁드립니다.
```
