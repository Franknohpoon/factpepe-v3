## 7️⃣ 앱 번들 (.ait) 업로드

토스 콘솔은 `.ait` 확장자의 앱 번들 파일을 요구합니다.

### 빌드 명령
```bash
npx ait build
```

### 산출물
| 항목 | 값 |
|---|---|
| 파일명 | `factpepe-incheon-baseball.ait` |
| 위치 | 프로젝트 루트 (`/Users/.../factpepe-v3.0-complete/`) |
| 크기 | 약 6.2 MB (토스 100MB 제한 통과) |
| 내부 구조 | RN 0.84.0 + RN 0.72.6 + 웹 번들 + manifest |

### 업로드 방법 (2가지)

**방법 1: 콘솔 직접 업로드 (Recommended)**
1. 토스 개발자 콘솔 → 워크스페이스 → 앱 선택
2. 좌측 메뉴 **앱 출시**
3. `factpepe-incheon-baseball.ait` 파일 업로드
4. 자동 생성된 **테스트 QR 코드** 스캔 → 토스앱 내 테스트
5. 최소 1회 테스트 완료 → **검토 요청**

**방법 2: CI/CD 명령어 (SDK v1.4.0+)**
```bash
# 콘솔에서 API 키 발급 후
npx ait token add
npx ait deploy -m "출시 v1.0"
```

### 주의사항
- `intoss://` 는 정식 출시 후에만 동작. 출시 전 테스트는 `intoss-private://` + `_deploymentId` 사용.
- QR 테스트 조건: 토스 로그인 + 워크스페이스 멤버 + 만 19세 이상
