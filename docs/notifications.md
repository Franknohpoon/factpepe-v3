# 푸시 알림 운영 가이드 (B. 경기 알림)

토스 미니앱 푸시는 **토스가 직접 발송**합니다. 우리는 두 가지만 합니다:
1. 클라이언트에서 사용자에게 **동의 UI**를 띄움 (`requestNotificationAgreement`)
2. 토스 콘솔에서 **발송**(콘솔 캠페인 또는 토스 발송 요청)

---

## 1) 토스 콘솔에서 동의문 등록

> 콘솔 → **스마트 발송 → 알림 동의문** → "+ 동의문 만들기"

### 동의문 ①: 경기 시작·결과 알림
| 항목 | 값 |
|---|---|
| 이름 (내부 식별) | `game_start_result` |
| 발송 시점 | 경기 시작 10분 전, 종료 직후 |
| 발송 방법 | 토스 발송 요청 (또는 직접 API) |

→ 발급된 **templateCode**를 Vercel 환경변수 `VITE_PUSH_TPL_GAME_START`에 추가

### 동의문 ② (선택): 적중·직관 알림
| 항목 | 값 |
|---|---|
| 이름 | `hit_visit` |
| 발송 시점 | 적중 확정, 직관일 당일 아침 |

→ Vercel 환경변수 `VITE_PUSH_TPL_HIT`

> 환경변수 추가 후 **재배포 필수** (Vite는 빌드 타임 주입).

---

## 2) 발송 카피 초안 (콘텐츠 규정 준수)

토스 규정: 제목 ≤ 7자, 본문 ≤ 25자, "토스" 포함, "지금 바로!" 같은 과장 금지.

### 경기 시작 10분 전
| 필드 | 카피 |
|---|---|
| 제목 | `오늘의 경기` |
| 본문 | `토스에서 SSG 경기 시작을 알려드려요.` (22자) |

### 경기 종료 직후 (SSG 승리)
| 필드 | 카피 |
|---|---|
| 제목 | `승리 소식` |
| 본문 | `토스에서 SSG 오늘 결과를 확인해보세요.` (23자) |

### 적중 확정
| 필드 | 카피 |
|---|---|
| 제목 | `예측 적중` |
| 본문 | `토스에서 오늘 적중 결과를 받아보세요.` (22자) |

### 직관일 아침
| 필드 | 카피 |
|---|---|
| 제목 | `직관 안내` |
| 본문 | `토스에서 오늘 직관 정보를 확인하세요.` (22자) |

---

## 3) 클라이언트 동작

- MY 탭의 **알림 카드**가 사용자에게 동의 UI를 띄움
- 결과 4종:
  - `newAgreement` — 이번에 새로 동의
  - `alreadyAgreed` — 이미 동의함
  - `agreementRejected` — 거부 (다시 누르면 재요청)
  - `unsupported` — 토스 웹뷰 밖(브라우저/Vercel)

- 모든 결과는 `analytics/push/{scenario}/{result}` 카운터로 누적

---

## 4) 발송 운영 흐름

### 방식 A: 토스 콘솔에서 운영자가 수동/예약
1. 콘솔 → 스마트 발송 → 캠페인 생성
2. 동의문(`game_start_result`) 선택
3. 카피 입력 → 검수 → 예약 발송
4. 매일 경기 시간에 맞춰 운영자가 직접 등록 (MVP)

### 방식 B: 토스 발송 API 직접 호출 (자동화, 후속)
- 토스에서 API 키 발급 필요
- Vercel 크론에서 경기 시작 10분 전 / 결과 확정 시 자동 호출
- 시간 절약 + 정확한 타이밍 — 검수 통과 후 별도 작업
